# پنل مدیریت بَراه — پیش‌نمایش

## مسیر
پس از اجرای برنامه، مسیر `/admin` پنل مدیریت نمایشی را باز می‌کند.

## امکانات رابط کاربری
- نمای کلی و کارت‌های شاخص
- نمودار روند فعالیت و ترکیب نقش کاربران
- فهرست کاربران با جست‌وجو، فیلتر نقش/وضعیت، پرونده نمونه و خروجی CSV
- جدول بارها و سفرها
- تاریخچه رویدادهای نمونه همراه با تاریخ و ساعت
- نمای صف احراز هویت، گزارش‌ها و امنیت
- طراحی راست‌به‌چپ و واکنش‌گرا برای موبایل و دسکتاپ

## محدودیت مهم
این PR فقط رابط کاربری و داده‌های ساختگی برای طراحی و ارزیابی گردش کار را اضافه می‌کند. برنامه فعلی از localStorage و ورود آزمایشی استفاده می‌کند و هنوز منبع داده مرکزی و ثبت رویدادهای سمت سرور ندارد. بنابراین:
- اعداد، کاربران، بارها، زمان‌ها و رویدادهای پنل ساختگی هستند.
- اطلاعات واقعی همه کاربران را نمایش نمی‌دهد.
- خروجی CSV فقط ردیف‌های نمونه را صادر می‌کند.
- مدارک هویتی بارگذاری یا نمایش داده نمی‌شوند و عملیات تأیید/رد واقعی وجود ندارد.
- مسیر `/admin` در این مرحله احراز هویت مدیریتی ندارد و نباید به عنوان پنل امن تولیدی تلقی شود.

## الزامات پیش از استفاده واقعی
1. پیاده‌سازی احراز هویت واقعی و نقش مدیر با بررسی سمت سرور؛ نه اتکا به مسیر فرانت‌اند یا localStorage.
2. تعریف schema و اتصال داده‌های کاربران، بارها، پیشنهادها، سفرها و تراکنش‌ها به پایگاه داده.
3. ثبت رویدادهای ممیزی سمت سرور با زمان UTC، actor، نوع رویداد، target و نتیجه؛ نمایش ساعت بر اساس منطقه زمانی انتخابی.
4. دسترسی به مدارک فقط از Storage خصوصی با RLS و مجوز سروری، به همراه سیاست نگهداری/حذف.
5. تست دسترسی، تست واحد/ساخت و بررسی workflowهای CI و سپس انتشار کنترل‌شده.
